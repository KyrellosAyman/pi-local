# Strata source review for Pi Local

Keep Pi as the desktop app and model-service owner. Take the measurement, caching, and validation ideas first. Treat Strata’s inference engine as an optional backend experiment with its own model and fixture results. Upstream explicitly supports Pi as an API client. [Supported clients](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/README.md#L125-L146)

## What the engine does

Flash-Next is a sparse mixture-of-experts model. Strata puts the shared layers and hot experts on the GPU, holds the experts in system RAM, runs cold experts on the CPU, and fetches small embedding lookup rows from SSD. It streams layers ahead during prompt processing and can keep the most-read part of the KV cache on the GPU beyond 64k. Its MTP head drafts from the model. Prompt lookup drafts text already present in the context, which is promising for source quotation and repetitive edits. Pi’s current dense GGUF reports `qwen35`. Strata has engine paths for Flash-Next (`qwen4exp`) and Qwen3.6-35B-A3B (`qwen35moe`). Replacing the backend with either would also change the weights and their behavior. [Engine and memory layout](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/docs/HOW_IT_WORKS.md#L12-L53) [Model dispatch](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/engine/include/strata/artifact/model_family.hpp#L15-L63)

The closest published hardware report uses an RTX 5060 Ti with 16 GB of VRAM and 64 GB of RAM, paired with a different CPU. Its coding variant had median decode rates of 47.46, 51.02, and 49.13 tokens/s at 4k, 32k, and 128k. The 128k request still waited roughly 69 seconds for its first token. Those were cache misses with short outputs and thinking disabled. Higher figures in the report used a different model and a workload-trained expert profile. The coding variant trades some general and language ability for its size and focus. Neither result establishes Pi’s speed or accuracy on the same tasks. [Community benchmark](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/docs/bench-results/2026-10-09-community-rtx-5060-ti-e5-2680-v4/README.md#L65-L111) [Model variants](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/docs/MODELS.md#L98-L123)

## Local verification of the upstream source

On Windows, 239 targeted Python tests passed. Five tokenizer tests skipped because the model pack was absent. The standalone C++ cache test passed 13,534 checks and the probabilistic sampler passed all 72 synthetic cases. The Python tests covered tool-call parsing and retry, cancellation, structured output, API streaming, the benchmark protocol, and tuning decisions. These runs exercised code paths without measuring Flash-Next inference. ### Cache identity and correctness

Strata’s conversation cache matches exact token prefixes, image identities, and steering state. It bounds parked state by bytes and distinguishes a shared pinned prefix from per-chat state. Its parity fixture compares token and state hashes, covers A to B to A restoration, and exercises forced eviction and oversized entries. Pi should use the loaded model, template, effective messages, tool schema, image bytes, and steering when checking which prefix remains valid. Reusing inference state and recovering a durable job need separate evidence. [Conversation cache policy](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/engine/include/strata/core/conversation_cache.hpp#L225-L245) [Conversation parity fixture](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/terminal/tools/conversation_cache_parity.py#L72-L150)

### Accuracy checks

Strata’s structured-output checker rejects incomplete generations, duplicate keys, and malformed payloads. Certain escape repairs are opt-in. Its OpenAI handler rejects undeclared tool calls and can suggest a close declared name during a bounded regeneration. Preserve those principles without allowing middleware to invent an executable call. Where task results can be graded, use exact artifact checks and independent review alongside sampling and generation metrics. The upstream twelve-case smoke suite covers instructions, retrieval, and tools. Truncated generations count as failures even when their speed is recorded. [Structured validation](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/terminal/serve/structured.py#L248-L304) [Tool correction path](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/terminal/serve/server.py#L5657-L5719) [Benchmark protocol](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/docs/BENCHMARK_PROTOCOL.md#L193-L229)

### Performance and numerical equivalence

Strata’s tuner measures the spread between repeated defaults and drift after trying candidates. Its acceptance threshold accounts for both, with a separate limit on prompt-processing regression. Copy the comparison method using Pi’s existing telemetry. Try cache and placement changes before kernels or numeric settings that can shift answers. The upstream NVIDIA defaults document measured logit differences for one quantized matrix kernel. Strata’s optional probabilistic verifier instead accepts drafts with a target-to-drafter probability ratio and samples from the remaining target distribution after rejection. Distributional parity and identical seeded output are distinct checks. [Paired tuner](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/terminal/strata_control/autotune.py#L160-L187) [NVIDIA tuning defaults](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/engine/include/strata/core/nv_defaults.hpp#L26-L68) [Probabilistic verifier](https://github.com/Niko1221/Strata/blob/3142b66b96e9c0e775e30f620b11b191a1427c2a/engine/include/strata/core/spec_prob.hpp#L1-L25)

### Hardware fit and deployment

Upstream lists roughly 39.2 GB of combined model residency and 35.5 GB of expert RAM for full Flash-Next IQ2_XS. These are estimates before verifying working buffers, context and Windows overhead. The model downloads include dense and expert files and a lookup table. MTP and vision add files and memory. An occupied GPU and other desktop workloads can materially change fit. Check the exact file sizes and spare capacity immediately before any experiment. Keep Pi’s model runner on loopback and let Pi own the service lifecycle.
