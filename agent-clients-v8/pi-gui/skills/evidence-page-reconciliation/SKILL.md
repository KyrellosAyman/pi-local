# Evidence-page reconciliation

Read the brief and freeze the ordered source list. Record file hashes, exact output fields, allowed authorities, cutoff and tie rules. Treat mechanical inventory rows, annotations and claimed outcomes according to the brief.

When complete source delivery is required, open each original in order. Use bounded page or line reads and follow any continuation cursor. Record an original source as fully reviewed only after its entire exact text has been delivered. An extraction script can verify or calculate results, but its summary alone cannot prove the model received each original. Confirm the final portion of each file and preserve the chronology before moving on.

After each group, save the completed source ranges and any exact excerpts that affect the decision. Keep their original file, line numbers and source hash. Save any unresolved conflicts and the next unread point. After restart or compaction, verify the checkpoint against the source hashes and reopen exact ranges that were omitted or are disputed before making a decision.

Normalize times consistently and follow the specified authority and correction rules. A retraction affects only its stated target. Keep uncertainty where the sources disagree or fail to establish a result. Bind each selected claim to the specific supporting record and retain original IDs and wording where required.

Write the requested output only after checking the input inventory and review coverage. Recompute the totals independently, validate the full output shape, verify each citation and confirm the input hashes stayed unchanged. Report any gaps in original delivery or source support even if the totals are correct.
