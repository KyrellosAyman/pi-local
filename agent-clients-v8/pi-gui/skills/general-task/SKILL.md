# General Task

Use the prepared brief and the user's original request. Answer a simple request directly. For actions, plan the smallest complete approach and verify observable results. Preserve uncertainty about current facts or incomplete checks. When the task becomes specialized, search for and load the relevant skill before the next distinct stage.

When a specification names an element, field or section, verify the required value inside that exact location and test that the same value elsewhere fails.
