# Pi Local matched follow-up, 22 November 2026

This entry supplements the [v0.1.3 evidence ledger](2026-11-22.md) with browser, plan-review, and near-64k cache trials. The [v0.1.4 technical report](../pi-local-v0.1.4.pdf) retains the earlier results and limitations.

| Trial | Observed result | Scope |
| --- | --- | --- |
| Signed-in Chrome | One scoped control read through a normal visible Pi chat. The browser tool returned the address and requested control. The chat took no page actions. | One read-only control. The legacy clients were closed. Production OAuth remained open. |
| Browser route | Skill searches fell from two to one and catalog discovery calls from one to zero. Total time was 309.774 and 306.540 seconds. | One paired prompt, same browser and native model process. |
| Accept a complete plan | First-plan retries fell from two to zero. Draft-to-review time fell from 64.336 to 13.065 seconds, with full time falling from 306.540 to 159.128 seconds. | Same browser request, model process, and tool routing. Both arms finished the requested read. |
| Near-64k desktop attribution | Fourteen native requests matched across two runs. Prompt processing accounted for 94.74% and 94.61% of total time. | Ten post-tool waits over 100 seconds. None of the 528 host samples reached joint 95% CPU and RAM. |

The native cache probe froze a file read, a plan update, and a final build code. It changed the offered tools at each stage. The model used the same optimized 64,000-token profile in all three arms. Reasoning was closed in the raw prompt for every arm. A strict text grader first rejected a permitted lead-in to a tool call. The tool name, arguments, and exact final code were then checked separately.

| Prompt setup | Native request time | Reused tokens on the three operations |
| --- | ---: | --- |
| Current order | 456.887 s | 0, 0, 0 |
| Alternate order | 454.055 s | 0, 0, 0 |
| Alternate with one warmup | 156.467 s | 59,655, 59,651, 59,651 |

The warmed sum includes 149.928 seconds of prompt evaluation. The observer stopped after that request when a native timing counter reported one token with zero decode time. The probe resumed from the same verified native task without a repeated warmup. The table sums request durations and excludes that observer interval. Decode stayed below 40 tokens/s and the production chat API and Pi GUI cache qualification remained open.

To repeat the release fixtures, use the [reproduction guide](../../docs/reproducibility.md#offline-fixture-checks). The alternate prompt is an experimental comparison.
